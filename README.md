# 文本模型测试工具

用 Groq 免费层测 API 文本模型：同一批模型、同一套题、同一提示词、
同一输出上限、同一思考档，途中不换模型。分数可比，不靠换模型省 token。

只用 Python 标准库，不需要 pip 装任何依赖。Python 3.8+ 即可。

## 准备

1. 在 Groq 控制台申请一个免费 API key。
2. 设置环境变量（key 只从这里读，不写进代码和日志）：

```bash
export GROQ_API_KEY=你的key
```

默认模型是 Groq 上的 qwen/qwen3.8-27b、openai/gpt-oss-120b、openai/gpt-oss-20b
（2026-10-31 实测可用）。模型改名或下线会报 404，用 `--models` 换成当时可用的 ID 即可。
免费层有限速（每分钟 30 次左右），脚本默认放慢节奏、撞 429 只等 60 秒重试一次。

## 两版分工

### 普通版：长文本生成版（questions_normal.json，17 道）

每道要求约 1500 字。判分重点不是答案对错，而是：结构全不全、
字数控不控制、越写越跑题没有、编没编数据/人名/政策/出处、重复啰嗦没有。

- 议论文、说明文、工作长文、演讲稿、故事/文案、长文改写、推理长文
- 输出上限：每道 2000 token

### 进阶版（questions_advanced.json，31 道代表题）

题目类 9 条：事实陷阱、过时信息、数学换算、偷换概念、指令冲突、
拒绝、语言文字、口语改写、代码与算法。
玩法类 4 条：盲测、稳定性（同一题换三种问法）、翻车集锦、性价比榜。
难度四档：基础、进阶、大学（含高数）、极限。

题量说明：进阶版目前是 31 道代表题，不是 70 道满版。
先用这 31 道试跑、找问题、修订策略，再扩到满版。

## 高效压缩作业对比（compress_compare.py）

测的是“用压缩 token 作业，模型还能不能高效产出”，不是工具本身省 token。

做法：同一道题，正常版 vs 压缩版，同一模型跑两遍。
压缩版 = 去客套话、符号化、只留关键数据、只输出结果。
例如经费题正常版是完整背景加分步骤要求，压缩版直接是：

```text
30人;交通600;门票900;午餐750;保险150;合计?人均?只写两个数字。
```

所有模型统一用 reasoning_effort=low。判分口径：headline 只算非敏感题，
多约束决策题（如预算、人数、天数三约束的 C07）压缩后全模型丢分，单独列、不计 headline；
429 没跑出来的题不计分母；压缩后 token 反增的题逐题列出。

注意：run.py 的 `--compress` 是另一回事——工具本身跑得便宜
（提示词去多余空白、思考档统一 low、不放宽上限、可设 --token-budget），
它的分数只作探索参考，不和压缩作业对比混用。

## 运行方式

```bash
# 只看计划和 token 上限估算，不调接口
python3 run.py --version normal --dry-run
python3 run.py --version advanced --dry-run

# 小批量试跑：普通版前 2 道，3 个代表模型
python3 run.py --version normal --limit 2 \
  --models qwen/qwen3.8-27b,openai/gpt-oss-120b,openai/gpt-oss-20b

# 进阶版只跑基础档
python3 run.py --version advanced --tier 基础

# 高效压缩对比（10 道，正常版和压缩版各跑一遍）
python3 compress_compare.py --sleep 3
```

输出：results/<版本>-<时间戳>/ 下有 results.json（每道题原始输出、耗时、token、
自动判分）和 report.md（正确率只算自动可判的题，长文本题留人工复核栏，不硬判文笔好坏）。

## 判分规则

- 事实/数学：看关键点/最终数字在不在，数字题以最终答案为准。
- 拒绝：看有没有拒绝、给没给合法替代，半推半就编一半算错。
- 代码：提取第一个 python 代码块，用题目自带的测试数据真跑一遍，通过才算对，
  超时 5 秒、报错、跑不通都算错，不只看代码像不像。
- 长文本：机器只量字数、查禁编项（是否出现题目没给的数据/人名/政策名）、
  查重复段落；结构、跑题、文笔留人工复核栏，不由机器硬判。
- 稳定性：同一题三种问法答案不一致，记一次不稳定，不计入单题正确率。
- 盲测：报告里模型名用代号，人工投票后再揭晓，工具不替人投票。
- 429 没跑出来的题不是模型答错，正确率分母要去掉；三模型全挂的题单独列，
  更可能是题目或判分过严，需人工复核。

## 一轮实测结论（2026-10-31，Groq 免费层，统一 low 思考档）

- 压缩对比：非敏感题 qwen 正常 4/7→压缩 5/7、省 42.1%；
  120b 4/7→4/7、省 36.6%；20b 4/7→3/7、省 40.7%。
  敏感题 C07 压缩后三模型全丢；拒绝题和事实陷阱题压缩后 token 反增。
  结论：压缩对普通题没伤，伤的是多约束题。
- 进阶版：qwen 10/18、120b 11/18、20b 12/18，20b 平均每题 token 最低；
  A01、A03、A04、A06、A14、A22 六道三模型全挂，待人工复核。
- 普通版：qwen 撞 429 的题多、基本不可比；120b 3/5、20b 4/5，共同失败只有 N15。
- 总判断：进阶版 20b 领先且最省，普通版 20b 最稳。
